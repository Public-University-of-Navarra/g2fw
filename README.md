# g2fw

Firmware of the Group 2 drone sensor board (ESP32), built in the firmware lab of
Desarrollo de Equipos Electrónicos (MUII, UPNA).

- The firmware lives in [`fw/`](fw/). Its contract (APIs, pins, serial format, rules) is
  [`fw/README.md`](fw/README.md).
- Every task is an issue. Work on a branch, open a PR with `Closes #<issue>`, wait for CI and
  one approval, and the PR is squash-merged into `main`.
